## Definition of Done
Focused tests prove that public configuration and secrets are separate, required secrets fail closed, and neither generic serialization nor default diagnostics reveal raw or encoded sentinel credentials. Recursive redaction covers nested structures, structured-log arguments, credential-bearing URLs, sensitive query parameters, and chained exceptions/subprocess failures while leaving the source object and canonical evidence bytes/hashes unchanged. Every security/health fixture is provenance-marked synthetic and production-like or unmarked fixture provenance is rejected. Default DB lifecycle, verifier, and `kl db-reset` plain/JSON output is credential-free while existing worktree isolation/reset tooling continues to pass. Redaction is a presentation/observability transform only: it cannot admit evidence, alter canonical evidence, derive a production actor/capability, or grant command/authorization authority.
