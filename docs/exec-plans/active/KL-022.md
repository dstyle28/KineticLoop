## Goal
Implement only the residual **Authorization evaluator + validity closure** behavior not already merged by KL-015, KL-018, and KL-021.

KL-015 already owns the command transaction, the S51-to-S01 lock order, T6 atomic issuance writes, current manifest/epoch/fence/validation guards, the exact leased artifact closure, and the T7 prescription/authorization query. KL-018 already owns immutable S49 registration, complete bounded transitive dependency admission, NULL-total validity, and explicit registered-policy approval for TIMELESS artifacts. KL-021 already owns T2-GLOBAL revoke commit semantics and current T3/T6/T7 denial after a committed revoke.

KL-022 must add one reusable, deterministic authorization evaluator and call it from the existing T6/T7 transaction-owner path. The residual evaluator owns: server-side minimum-validity calculation and certificate validation; fail-closed missing/undefined validity; approved TIMELESS handling without converting TIMELESS into an infinite S42; exact subject/content/scope/epoch/control-state/time eligibility; and a non-bearer `is_executable` result that is recomputed from current authoritative state. It may refactor the merged inline calculations into the evaluator, but must not create a second transaction owner, a second registry gate, a migration, or a parallel authorization store.
